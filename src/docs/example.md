# Памятка об учебном ассистенте

Команда `/chat` отвечает на обычный вопрос и помнит последние реплики текущего сеанса. Команда `/steps` превращает задачу в короткий список шагов. Команда `/plan` может добавить задачу в локальный план или показать текущие задачи.

# Поиск по заметкам

Команда `/rag` всегда ищет фрагменты в выбранных текстовых файлах и затем формирует ответ. Команда `/agent` позволяет модели решить, нужен ли поиск. Источники показываются только из фактически найденных файлов.

# Ограничения

История диалога хранится в памяти процесса. После завершения программы она исчезает. Заметки для поиска кладутся в папку `src/docs` в кодировке UTF-8.
