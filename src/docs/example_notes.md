# Учебные заметки

В понедельник нужно составить список задач на неделю. В пятницу следует проверить выполненные пункты и перенести незавершённые задачи в новый список.

Для короткой заметки достаточно заголовка и одного абзаца. Помощник может ответить на вопрос о содержимом этой заметки только после поиска по файлам.
